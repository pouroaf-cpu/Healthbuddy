Standard embed (recommended)

Drop this into any section, column, or content block where you want the calculator to appear.

<iframe src="https://www.injectbuddy.com/embed/calculator.html" width="100%" height="960" style="border:0;border-radius:12px;box-shadow:0 0 20px rgba(0,0,0,.16);" loading="lazy"> </iframe>

Uses the embedded TRT calculator layout with a small built-in credit back to InjectBuddy.

  • Width: 100% so it fills whatever container you place it in.
